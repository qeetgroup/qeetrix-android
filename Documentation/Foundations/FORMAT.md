# Formatting

`QeetrixFormat`, `QeetrixDateStyle`, `QeetrixTimeStyle`, `QeetrixDurationStyle` · `foundation.format` ·
`@qeetrix/react`: `format` (`formatNumber`, `formatCurrency`, `formatRelativeTime`, `formatDate`, `formatDateTime`) ·
QTRX-121

Numbers, money, dates and "2 minutes ago" written as the web writes them for the same locale: `en-IN` groups in lakhs
and crores and writes the rupee as ₹.

```kotlin
val india = Locale.forLanguageTag("en-IN")
QeetrixFormat.number(1234567, india)                 // "12,34,567"
QeetrixFormat.currency(124500, "INR", india)         // "₹1,24,500.00"
QeetrixFormat.percent(0.25, india)                   // "25%"
QeetrixFormat.relativeTime(sentAt, india)            // "2 minutes ago"
QeetrixFormat.date(LocalDate.of(2026, 10, 25), india) // "25 Oct 2026"
QeetrixFormat.dateTime(meeting, india)               // "25 Oct 2026, 2:30 pm"
QeetrixFormat.duration(Duration.ofMinutes(65), india) // "1 hour, 5 minutes"
```

| Web | Android | Rule |
|:--|:--|:--|
| `formatNumber` | `number`, `percent` | the locale's digits, grouping and signs; at most 3 fraction digits; ties away from zero |
| `formatCurrency` | `currency` | the currency's own fraction digits (two for INR); `maximumFractionDigits = 0` for whole amounts |
| `formatRelativeTime` | `relativeTime` | the largest whole unit, rounded first (59 min 40 s is "1 hour ago", 364 days "last year"); a month is 30 days |
| `formatDate`, `formatDateTime` | `date`, `dateTime` | always Gregorian; a `LocalDate` or `LocalDateTime` is never moved by a zone; an `Instant` is shown in a zone |
| — (QTRX-216) | `duration` | the non-zero units, largest first, as `Intl.DurationFormat` writes them |

Built on Android's own ICU (`android.icu`, no dependency). In a composable, pass `LocalConfiguration.current.locales[0]`
so the text follows a change of language; [Relative time](../Components/RelativeTime.md) keeps "2 minutes ago" current.

## Checked against the web

`qeetrix/src/test/resources/qeetrix/format-cases.json` holds 305 cases in five locales (en-IN, hi-IN, en-US, ar-EG,
de-DE): what the web's rules write on `Intl`, generated by `Tools/FormatCases/format-cases.mjs` (Node's ICU 78.2, CLDR
48). `QeetrixFormatTest` requires every one: 303 match exactly; 2 are recorded differences in Android's older ICU data
(German narrow hours, "Std." where CLDR 48 writes "h"), each excluded by name and required to keep happening.

## Platform differences

- **Zone.** An `Instant` is shown in the device's zone by default; the web fixes `Asia/Kolkata` so its server and
  client agree.
- **The space before "pm".** Android's ICU data has a narrow no-break space there; the web's current data a space.
  Qeetrix writes the web's.
- **Durations** have no web wrapper yet; Android follows `Intl.DurationFormat`.
- Options are parameters (`minimumFractionDigits`, `maximumFractionDigits`, `grouping`), not `Intl` option objects.
